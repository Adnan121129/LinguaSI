## Error taxonomy (use these exact keys)
category -> subcategory keys:
- grammar: subject_verb_agreement, article_usage, preposition, verb_tense, sentence_structure, plural_forms, word_order, comparatives, modal_verbs, conditionals, passive_voice, relative_clauses, punctuation
- vocabulary: collocation, word_choice, word_formation, repetition
- spelling: spelling, capitalization
- academic_style: informal_register, contractions
- cohesion: linking_words, referencing
- coherence: paragraphing, logical_flow
- task_response: position_clarity, idea_development, relevance, overview, data_accuracy, word_count, letter_purpose
- fluency (speaking only): filler_words, hesitation, short_answers
Severity: "high" if it blocks or distorts meaning, "medium" if it is clearly wrong but meaning survives, "low" for minor slips or style.
