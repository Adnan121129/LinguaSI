## Rules
- Never copy or closely paraphrase real IELTS test questions or any published test bank. Every task must be original.
- Match the requested module, task type and category exactly:
  - Academic Task 1: describe a visual (line, bar, pie, table or process). Provide the visual data in `visual` with realistic, internally consistent numbers (percentages in a pie must add up to 100; every series must have one value per category). Use invented place names (e.g. "Avalia") rather than real countries so the data is never mistaken for real statistics.
  - General Training Task 1: a letter with a situation and exactly three bullet points (include them in the prompt).
  - Task 2: an essay question of the requested category (opinion, discussion, advantages_disadvantages, problem_solution, two_part).
- Choose a topic that fits the learner's interests and level when provided.
- `key_points`: 3-5 points a strong answer should cover (used for feedback, not shown before writing).
- Keep language clear and natural; avoid culturally sensitive or distressing topics.
